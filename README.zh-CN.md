# Grill Lite

[English](README.md) · [技能规则](SKILL.md) · [MIT 许可证](LICENSE)

一个轻量的方案追问技能。保留关键质疑，用少量问题帮助你做决定，然后给出建议和下一步。

## 怎么问

- 默认**每轮 1–2 题，全程最多 5 题**。
- 信息足够就提前结束，也可以一道题都不问。
- 只追问会改变方向、范围或可行性的关键问题。
- 每题附简短建议和理由；小的可逆选择采用合理默认值，并标明假设。
- 按独立决策计数，一句话里塞三个问题仍然算三题。
- 你说“先给结论”“够了”或“直接做”，立即结束追问。
- 收尾给出建议、关键决定与假设，以及一个具体的下一步。

五题是整个讨论的上限，不是每条消息的上限。你可以指定其他上限，也可以主动要求继续深入。技能不会自动创建访谈记录文件，也不会增加额外的确认轮次。

## 安装

使用 [Skills CLI](https://github.com/vercel-labs/skills)：

```sh
npx skills add HUHANG716/grill-lite --skill grill-lite
```

全局安装到 Codex：

```sh
npx skills add HUHANG716/grill-lite --skill grill-lite --agent codex --global
```

其他支持技能的助手可在安装器中选择。核心规则是纯 Markdown，不需要运行脚本、配置 API 密钥或依赖特定工具。

手动安装时，将 `SKILL.md` 和可选的 `agents/` 文件夹放到助手技能目录下的 `grill-lite` 文件夹。分发副本时保留 `LICENSE`。Codex 的用户级路径之一为 `~/.agents/skills/grill-lite/`，详见[官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

## 使用

```text
用 $grill-lite 帮我过一下这个方案：……
```

也可以指定更少的问题：

```text
用 grill-lite 帮我看看这个想法，每轮只问一个，总共最多三个。
```

随时说“先给结论”就会收尾。如果你同时授权执行，助手会在结束讨论后按授权继续；单独要求评审，只会得到建议。

## 一个例子

**你：** 我想做一个个人任务管理工具，用 grill-lite 帮我看看。

**助手：** 第一版最想解决哪个问题：忘记任务、不知道先做什么，还是看不清进度？我建议先解决“不知道先做什么”，这样第一版有明确的用途。

**你：** 不知道先做什么。只给我自己用，也不需要同步。

**助手：** 建议先做本地的每日优先级视图。你已确定：个人使用、帮助选择下一项任务、不需要同步。我采用的假设是第一版手动录入任务就够了。下一步：画一张包含任务收件箱和今日三项重点的页面草图。

一次有效回答就可能足够，不要求把五题用完。

## 检查与贡献

[行为检查场景](EVALS.md)覆盖问题计数、提前停止、自定义上限和执行边界，供人工评估使用，不代表已通过自动化行为测试。提问上限依靠模型遵守指令，并非程序强制执行。

欢迎基于实际使用反馈改进：说明遇到的问题，并提供一个小例子。优先减少不必要的提问，避免不断叠加规则。
